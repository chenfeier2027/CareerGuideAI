高考志愿专业规划助手

简介：一个浏览器端的AI志愿咨询单页前端，引导考生一步步完成信息采集，自动生成专业推荐。本仓库只提供前端页面，不包含后端服务与任何API密钥。

功能特点：
1. 流程化收集填报关键信息：考生省份、新高考/传统文理选科、省位次或分数、意向上学地区、报考诉求、排斥的专业大类。
2. 对话约束一轮只问一个问题，用户不需要手动编写提示词，跟随AI回答即可。
3. 全部硬性信息收集完成后自动输出报告，包含优先推荐专业、备选专业、避雷专业。
4. 使用localStorage在浏览器本地保存会话，刷新页面聊天记录不会丢失。
5. AI回复支持Markdown格式渲染，附带代码块复制功能。
6. 内置多重兜底逻辑，避免大模型闲聊跑偏、重复提问、无限循环。

文件说明：
仓库内仅有 chat(10).html 这一个文件，HTML、CSS、JavaScript全部集成在这一个文件中，无需额外js文件。

使用步骤：
1. 后端需要自己部署阿里云函数计算FC，使用配套index.js代码。
配置环境变量 DASHSCOPE_API_KEY，填入自己的阿里云百炼API Key，部署后拿到HTTP触发器公网访问地址。
重要：后端index.js不要上传到公开仓库，防止密钥泄露被刷额度。
2. 本地打开 chat(10).html，找到代码里的 const API_URL = "";
把引号中间替换成你自己的FC触发器地址，保存文件。
3. 直接用浏览器打开修改后的html文件即可开始对话。
如果使用GitHub Pages，只能看到界面，必须配置后端接口以及FC跨域允许pages域名才可以发送消息。

后端接口约定
后端接收POST请求，请求JSON格式：
{
  "userContent": "用户输入文本",
  "systemPrompt": "系统提示词",
  "history": []
}
返回遵循OpenAI兼容格式：{"choices":[{"message":{"content":"AI回复内容"}}]}

重要提醒
1. 工具输出的所有专业建议仅供参考，不构成高考报考依据，最终填报请以各高校官方招生简章为准。
2. 严禁将API密钥、你的FC公网接口地址提交到公开仓库，避免被他人调用消耗余额。
3. 聊天过程出现接口报错，优先检查FC执行超时（建议设置90‑120秒，内存512MB）、API Key是否有效、账户是否有余额。

常见问题
Q：点击发送提示没有配置接口地址？
A：打开html文件，修改API_URL变量填入自己的后端触发器地址。

Q：对话中途报接口出错？
A：调高FC函数执行超时时间，检查API账户余额。

Q：GitHub Pages打开页面无法发送消息？
A：静态页面本身没有后端能力，需要部署FC，并且配置FC的跨域允许GitHub Pages域名。
